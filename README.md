# РЕЙС 400
### Тренажёр решений проводника · Хакатон Московского транспорта 2026

> **Рабочая концепция, а не готовое конкурсное решение.** Трек: **«Геймификация для ВСМ»**. Исследование на **19 сентября 2026 года**. Разработка конкурсного MVP — после открытия 25 сентября и проверки полного технического задания.

**Идея:** короткая интерактивная смена с развилками, ограничением времени, последствиями решений и разбором ошибок. Безопасность — обязательное условие успешного прохождения, а не баллы, которые можно компенсировать довольным пассажиром.

## Три важных ограничения

**1. Неоднозначное ТЗ.** Сайт и основной текст положения говорят об обучении сотрудников; приложение №3 — об игре и системе лояльности пассажиров. Расхождение не считаем разрешённым. До полного ТЗ выбираем обучение проводников как рабочую гипотезу.

**2. Права на результат.** Положение §14.2.2 предусматривает передачу исключительных прав по нашему кейсу Фонду «ТИМ». Повторное использование, публикация и портфолио ограничены §14.4–14.6. Команде необходимо самостоятельно ознакомиться с условиями до принятия; этот репозиторий не является согласием от её имени.

**3. Приватность.** Репозиторий остаётся **private**. Исходный чат содержит данные участников; его не включаем в публичное демо, GitHub Pages или материалы жюри. Лицензия на публичное распространение проекта не назначена.

## Статус решений

- Направление **РЕЙС 400** выбрано как стартовая рекомендация; не как уже согласованное решение заказчика.
- Текст заявки подготовлен; **заявка не отправлялась**, состав команды и допуск не подтверждены.
- Исследование не заменяет подробное ТЗ, которое ожидается 25 сентября.
- Интервью, пилот и измерения учебного эффекта ещё не проводились. Все целевые метрики ниже — план проверки, не полученные результаты.
