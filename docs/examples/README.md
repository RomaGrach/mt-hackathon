# Пример контракта смены v2 и границы проверки

[Gameplay](../GAMEPLAY.md) · [Предметная модель](../DOMAIN-MODEL.md) · [Handoff](../GAMEPLAY-HANDOFF.md)

## Файлы

- `shift-v2-contract.json`: серверный checkpoint после шага 2, соответствующий публичный вид без скрытого B, две команды, граничные серверные времена и четыре ожидаемых маршрута.
- `validate-shift-example.mjs`: самостоятельная проверка согласованности этого примера. Не импортирует production engine/service и не заменяет будущие тесты API/БД/UI.

Checkpoint не является полным архивом replay: закреплённые байты сценария/рубрик, initialSnapshot и полный журнал явно перечислены в omittedPersistence. Идентификаторы design-1 и unverified-demo-only обозначают синтетическую документационную фикстуру, а не опубликованный регламентный контент. Все шкалы, сроки и критерии авторские.

## Запуск

Из корня репозитория:

```sh
node docs/examples/validate-shift-example.mjs
```

Для проверки изменённого JSON можно передать путь первым аргументом. При нарушении assert процесс завершится ненулевым кодом.

## Фактически выполненная проверка в #21

**26.09.2026, локальная среда Linux, Node.js v22.16.0.** Это среда отдельного проверяющего скрипта, не изменение требуемого README Node.js 24 и не проверка запуска игры под Node.js 22.

Результат: **10 групп проверок прошли**, четыре ожидаемых маршрута согласованы. Проверены дискриминаторы state; ссылки и независимость дел; соответствие public checkpoint без скрытых идентификаторов; фиксированные критерии/evidence; requestId/revision; deadline−1/deadline/deadline+1; порядок scheduledEvents; арифметика шкал и отсутствие повторных критериев; ack не завершает Incident; guard-пропуски после своевременного действия.

Отдельно на временных копиях JSON внесены четыре повреждения. Все четыре отвергнуты скриптом с ненулевым кодом: раскрытие b-aisle в publicCheckpoint; неверная итоговая safety=91 вместо 90; aStatusAfter=resolved непосредственно после ack; повторное начисление predeparture на шаге обнаружения. Эти временные повреждённые файлы не являются содержимым репозитория.

## Что этим не доказано

Не запускались существующие unit/service/http/e2e тесты приложения, новая игра, deployment, Docker, реальная конкуренция запросов, публикация контента, миграции, серверный replay или UX на смартфоне. Публичная проекция проверяется как пример данных, не как действительная защита ещё не реализованного API. Арифметика ожидаемых трасс не доказывает, что runtime их воспроизводит.

План таких проверок T01–T19 находится в GAMEPLAY-HANDOFF.md и передан в #26/#27. Четыре класса обслуживания, второй содержательный вариант и профессиональная валидность рубрики требуют отдельного наполнения/сверки. Закрытие задачи #21 не закрывает эти работы.
