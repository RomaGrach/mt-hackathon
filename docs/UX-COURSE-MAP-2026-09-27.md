# Курс и карта: доработка отзыва после PR #37

## Что требовалось

Сохранить содержательную главную, разделить готовый курс и свободную тренировку, усложнять условия последовательно, показывать известные дела как доступные действия, убрать пустые промежуточные экраны ожидания/осмотра, добавить наглядный вагон с состояниями задач.

## Решение

- Четыре этапа курса, по два существующих варианта в каждом: Стандарт без срочного таймера, Комфорт с увеличенным временем, Бизнес со стандартным временем, Первый в режиме проверки. Это восемь комбинаций опубликованного содержания, не восемь новых уникальных сюжетов.
- Главная содержит продолжение/следующую смену, прогресс, раскрывающийся план и отдельную вкладку своей тренировки. Все классы/варианты по-прежнему доступны; искусственных блокировок нет.
- Прогресс вычисляется по сохранённым зачётным результатам с точным совпадением класса, варианта, режима и политики времени. Перепрохождение от развилки не засчитывается. Backend возвращает класс и политику в истории; клиент не начисляет результаты.
- В обзоре известное дело имеет явный focus. Резервный вывод больше не возвращает ожидание над задачей. Ожидание доступно при реальном ожидании коллеги; повторный осмотр/ожидание остаются в «Ещё».
- После inspect/wait клиент подтверждает серверный continue без лишнего промежуточного экрана. Обе команды идемпотентны, серверный журнал/начисления не меняются. Оценённые решения и timeout автоматически не подтверждаются; при сетевой ошибке сохраняется обычное восстановление квитанции.
- Карта — функциональная учебная схема мест с компоновкой 3+2, 2+2 или 2+1, выбранной по опубликованным данным. Точные реальные номера/геометрия не заявляются. Неизвестные инциденты не раскрываются. Цвет и текст обозначают открытое дело, ожидание, срочность/ошибку, решение.
- Карта и задачи используют только серверные разрешённые переходы; в критическом окне ограничения сохраняются. Backend добавляет incidentId к публичной задаче для адресного перехода.
- Рейтинги групп и подробный итоговый разбор оставлены: это требования CASE F06/F07. Ручной выбор бригады, дубль навигации и непрерывные объяснения не возвращены.

## Выпуск

Использовать существующий проект из `.openai/hosting.json`, выполнить `npm run check`, `npm test`, `npm run build:sites`, сохранить и опубликовать версию через обычный порядок из SITES-DEPLOYMENT.md. Новых зависимостей и D1-миграций нет.

После подтверждения коллеги текст обзора меняется, ожидание исчезает. Пройден путь до выполнения всех задач и доступного завершения (08:05:30, лояльность 85, безопасность 90).
