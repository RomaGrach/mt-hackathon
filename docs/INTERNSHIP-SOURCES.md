# Источники стажировок

Обновлено: 16.10.2026.

Этот файл — постоянный реестр сайтов, на которых мы ищем стажировки для студентов старших курсов и начинающих специалистов.

Фокус:
- ML / AI / Data Science;
- LLM / AI agents / Python;
- backend / infrastructure / DevOps;
- cybersecurity / SOC / AppSec / DevSecOps;
- Computer Vision;
- смежные технические роли, если они дают сильный инженерный опыт.

Хакатоны и соревнования сюда не включаем. Для них используется отдельный файл `docs/HACKATHON-SOURCES.md`.

## Как использовать

1. Сначала проверять агрегаторы — они дают широкий охват.
2. Затем проходить прямые карьерные страницы крупных компаний: часть стажировок не попадает в агрегаторы.
3. Для каждой вакансии проверять именно текущую карточку, а не старую поисковую выдачу.
4. Фиксировать:
   - открыт ли набор сейчас;
   - дедлайн;
   - курс/статус студента;
   - минимальную занятость;
   - удалённый/очный формат;
   - требования по специальности;
   - оплату;
   - стек и реальные задачи;
   - отзывы о стажировке и команде;
   - вероятность продолжения в штат.
5. Архивные вакансии не удалять из истории поиска, но не считать активными.

## 6. Правило расширения списка

Добавлять новый сайт в этот файл, если выполняется хотя бы одно условие:

- на нём регулярно публикуются студенческие стажировки;
- там есть отдельная программа для intern / trainee / студентов;
- сайт уже дал хотя бы одну релевантную вакансию по ML, AI, Python, CV, ИБ или инфраструктуре;
- компания публикует набор у себя раньше, чем он появляется на агрегаторах.

Не добавлять сюда:
- чистые хакатонные площадки;
- разовые конкурсы без стажировок;
- обычные новостные сайты;
- архивные лендинги одной завершённой вакансии.
