# Источники хакатонов и IT-соревнований

Обновлено: 14.10.2026.

Этот файл — общий реестр сайтов, которые уже использовались в проекте для поиска хакатонов, чемпионатов, CTF, ML/AI-соревнований и близких командных IT-активностей.

## Как использовать

1. Сначала проверять агрегаторы и календари.
2. Затем — прямые площадки крупных организаторов.
3. Отдельно просматривать международные и специализированные AI/CTF/engineering-площадки.
4. Для каждой найденной активности отдельно проверять: регистрация открыта ли сейчас, дедлайн, формат участия, ограничения по возрасту/статусу, состав команды, призы и возможность удалённого участия.
5. Не считать старую страницу мероприятия подтверждением открытого набора: статус всегда перепроверять на официальной странице.
