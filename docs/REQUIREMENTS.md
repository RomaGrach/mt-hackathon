## Функции задания

| ID | Требование | Состояние текущей игры | Граница подтверждения |
|---|---|---|---|
| REQ-F01 | Профиль, уровень, очки компетенций | Реализованы: серверный профиль, сумма результатов, уровень, история | Сохранение и расчёты покрыты тестами; перенос профиля между устройствами не реализован |
| REQ-F02 | Нелинейные диалоги и разные исходы | Реализованы: 27 ситуаций, 53 промежуточных узла, 182 маршрута к исходам | Проверены обходы и целостность контента; методическая экспертиза ещё нужна |
| REQ-F03 | Критический таймер | Реализован: 60/120 секунд, абсолютный серверный deadline | Проверены timeout и сохранение; доступность для разных пользователей требует пилота |
| REQ-F04 | Лояльность и безопасность | Реализованы обе шкалы и последствия решений | Игровые коэффициенты авторские, не норматив перевозчика |
| REQ-F05 | Достижения, бейджи, уровни | Частично: уровень и прогресс курса есть | Отдельные бейджи/достижения новой модели не подключены; legacy-награды не засчитываются как новая реализация |
| REQ-F06 | Рейтинги бригады, депо, компании | Реализованы три области по накопительным очкам | Группы демонстрационные; массовая нагрузка не проверена |
| REQ-F07 | Разбор последствий решений | Реализованы исход внутри карточки, лог и итоговый разбор | Разбор показывает фактические выборы и последствия; эффективность обучения не измерялась |
| REQ-F08 | Уведомления о сценариях, челленджах, истечении баллов | Не включены в текущий интерфейс по принятому продуктовому решению | Это разрыв с исходным пунктом задания. Лог смены не заменяет такие уведомления |
| REQ-F09 | Аналитика действий и пробелов | Частично: история, результаты, ошибки и пропущенные задачи | Нет валидированной модели профессиональных компетенций и полноценной корпоративной аналитики |

## Игровые и технические уточнения

| Требование | Состояние и доказательство |
|---|---|
| Одновременные дела и приоритеты | Известные проблемы и рабочие задачи в одном экране, двумя группами; конечные внутренние сроки |
| Обнаружение скрытых событий | Осмотр вагона открывает только обнаруженные проблемы; будущие события не видны заранее |
| Рандомизация | Пул проблем и места выбираются при создании смены; закреплённая версия и seed сохраняют воспроизводимость |
| Четыре класса | Стандарт, Комфорт, Бизнес, Первый; 8 готовых этапов курса и своя тренировка |
| Администратор | Открытая read-only сводка синтетических профилей; редактор сценариев и защищённые корпоративные роли не реализованы |
| Мобильный интерфейс | Проверены viewport 390×844 и 320×740; это браузерная проверка, не физический телефон/Safari |
| Авторитетный сервер | Серверные баллы и deadline; revision, requestId, транзакции и закреплённый контент |
| Постоянное хранение | SQLite в Node; отдельный адаптер Sites/D1 сохранён как альтернативный |
| HR/LMS API | Есть опциональный read-only экспорт с ключом; реальная интеграция с системой заказчика не выполнена |
| Масштабирование и ИБ | Архитектура расширяемая; нагрузка, SSO/RBAC, аудит и промышленная эксплуатация остаются планом развития |
