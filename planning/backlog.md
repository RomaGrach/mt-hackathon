## Перед отправкой решения

- [ ] Все обязательные пункты полного ТЗ сопоставлены с реализованными функциями.
- [ ] Указаны фактическое число сценариев, реализованные возможности и ограничения.
- [ ] Есть запускаемый прототип, инструкция, презентация и запрошенные платформой материалы.
- [ ] Использованные зависимости, ассеты, модели, данные и предварительное исследование перечислены.
- [ ] Нет токенов, сырых сообщений третьих лиц, неразрешённых инструкций и персональных данных.
- [ ] Доступ жюри протестирован; private-репозиторий не сделан публичным ради удобства.
- [ ] Зафиксированы commit SHA, версия сценариев, сборка и контрольные суммы.
- [ ] Сохранено подтверждение загрузки до 27.09.2026, 23:59 МСК.

## Шаблон записи решения

`Дата → вопрос → принятое решение → основание/источник → последствия → ответственный → когда пересмотреть`.

Не отмечать чекбокс выполненным только потому, что в документе описан желаемый результат. При нехватке времени первым сокращается дополнительный контент, а не надёжность главного маршрута.
